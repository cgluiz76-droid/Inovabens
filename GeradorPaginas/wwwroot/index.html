Login necessário

    1. Abra um terminal (PowerShell ou Prompt de Comando) com o mesmo usuário do Windows que roda esta ferramenta.
    2. Digite claude e tecle Enter. Se o comando não existir, instale o Claude Code (veja o README).
    3. Dentro do Claude Code, digite /login, escolha a conta da assinatura Claude (não “API key”) e conclua no navegador.
    4. Saia com /exit e clique em Verificar novamente.
